# 麻将分析 - 网页版

与 iOS 应用同功能的单页网站：14 张手牌、打每张后的向听数与进张面、能上听总张数、推荐方案、一键清空、理牌、七对子可选。

**在线访问**：<https://matrix-3d.github.io/majiang/>

## 运行方式

在项目根目录或 `web` 目录下启动任意静态服务器，用浏览器打开 `index.html` 即可。

**方式一（Python 3）**
```bash
cd web
python3 -m http.server 8080
```
浏览器访问：http://localhost:8080

**方式二（Node）**
```bash
cd web
npx serve -p 8080
```

**方式三**  
直接用浏览器打开 `web/index.html`（部分功能可能受 file:// 限制，建议用本地服务器）。

## 目录结构

```
web/
├── index.html      # 页面结构
├── css/style.css   # 样式（绿毡风格）
├── js/
│   ├── mahjong.js  # 规则、向听数、分析、推荐
│   └── app.js      # 界面逻辑与渲染
└── README.md
```

## 功能说明

- **规则与设置**：手牌 14 张、每种最多 4 张；「考虑七对子」开关。
- **当前手牌**：显示已选牌，点击牌面可移除；**理牌**、**一键清空**。
- **选牌**：34 种牌网格，点击添加，显示已选数量。
- **开始分析**：满 14 张后出现，点击后展示结果。
- **结果**：推荐方案卡片；每条「打某张」的向听数、能上听总张数、上听进张与改善进张（含剩余/共 4 张）。
